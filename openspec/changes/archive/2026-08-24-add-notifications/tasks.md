## 2. 通知の時刻の判定

design.md D3・D4 に対応する。cron の中心なので、純粋関数として切り出してテストする。

- [x] 2.1 「ある時刻に、ある利用者へ送るべきか」を判定する純粋関数を書く。利用者の地域・指定時刻・現在時刻・最後に送った日を受け取る。時計を内部で読まないこと。検証: 型チェックが通り、その関数が D1・HTTP・フレームワークを import していないこと
- [x] 2.2 時刻が一致する利用者だけが対象になることをテストする。検証: 同じ瞬間に、地域の違う複数の利用者を並べ、指定時刻と一致する者だけが選ばれることを確認する
- [x] 2.3 同じ日に二度送らないことをテストする。検証: 一度送った記録がある利用者は、同じ日の後続の起動で対象にならないこと。**日付の判定は利用者の地域で行う**こと
- [x] 2.4 不正な地域名を持つ利用者を飛ばし、他の利用者への配信を止めないことをテストする。検証: 壊れた設定の利用者を混ぜても、正常な利用者が対象に残ること
- [x] 2.5 通知を切っている利用者が対象にならないことをテストする
