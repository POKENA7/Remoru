## Context

動機は proposal.md、要件は `specs/`。

いまシートは2つある。

| | 中身 | 閉じたときに失うもの |
|---|---|---|
| 削除の確認（`memo-detail`） | 文だけ | 無し |
| 書き直し（`quiz-sheet`） | 本文・問・答の入力 | 書きかけ |

どちらも `.sheet-backdrop` > `.sheet` の形で、`.grip` を描いている。
**`.grip` は飾りで、引く実装は無い。**

既にある作法:

```
app/memo-detail.tsx:166
  // 選び手の外に触れたら閉じる。スマホには Escape が無い（design.md D1）
```

タグの選び手は外側を押すと閉じる。シートだけがその作法から外れている。

`.sheet` は `max-height: 88dvh; overflow-y: auto` なので、**中身がスクロール
しうる**。引く操作とスクロールが取り合う。

## Goals / Non-Goals

**Goals:**

- ボタンを探さずに閉じられる
- 掴み手が本当に掴める
- 引けない利用者の手段を失わない
- 2つのシートが同じ閉じ方を持つ

**Non-Goals:**

- 閉じるときに確認を挟むこと（速さを優先する、D2）
- 書きかけを次に開いたとき復元すること
- シートの高さを段階的に変えること（iOS の detent 相当）
- 復習画面や通知の設定（シートではない）

## Decisions

### D1: 閉じ方を1箇所にまとめる。**2つのシートに同じものを配る**

いま2つのシートが別々に `.sheet-backdrop` を書いている。閉じ方を足すと、
片方だけ直したときに静かにずれる。

外枠を1つの部品にして、中身だけを差し替える形にする。

```
Sheet（新しい部品）
  ├ 外側を押す・引く・Escape・焦点戻し
  └ 中身:  削除の確認  /  書き直しの入力
```

**閉じ方の規則は spec（`sheet`）に書き、実装は1箇所に置く。** どちらも
「同じ規則をどのシートにも」を担保する仕掛けである。

### D2: 入力があっても、確認せずに閉じる

iOS は `interactiveDismissDisabled` を「変更があるときだけ」有効にして
確認を挟む形を採る。**それは採らない。**

| | 手数 | 失うもの |
|---|---|---|
| 確認を挟む | 閉じるたびに1手 | 無し |
| **挟まない**（採用） | 0 | うっかり閉じたときの書きかけ |

このアプリのシートは短く（欄は最大3つ）、書き直しはいつでもやり直せる。
**取り消せない操作（削除）は閉じても実行されない**ので、確認が守るのは
数十文字の打ち直しだけになる。

書きかけを次に開いたときに戻す案も考えたが、**閉じたのに残っている**のは
それはそれで驚く。閉じたら消える、で揃える。

### D3: 引けるのは、中身が一番上にあるときだけ

`.sheet` は中身をスクロールできる。途中まで下げた状態から引けると、
**読もうとして下げただけで閉じる**。

```
scrollTop > 0   → 中身をスクロールする。シートは動かない
scrollTop === 0 → シートを引く
```

掴み手の上は中身の外なので、**そこからは常に引ける**。

### D4: 引く距離と速さの両方で決める

距離だけで決めると、速く弾いたのに閉じない。速さだけで決めると、ゆっくり
大きく引いたのに閉じない。

```
閉じる = 引いた距離 > シートの高さの 1/4
       または  離した瞬間の速さ > 0.5 px/ms（下向き）
```

上へは引けない（`translateY` は 0 以上）。上に伸びると、シートが画面より
高くなる形が生まれる。

### D5: 引いている間は指に追随させる。動きを止めた人には出さない

引いた分だけ `translateY` する。離したら、閉じるなら下へ抜け、閉じないなら
元へ戻る。

`prefers-reduced-motion` では**追随も戻りも出さない**（`motion` の要件）。
引く操作そのものは残るが、指に追いかけて動く表現をやめ、**閉じるか閉じないか
の結果だけ**を出す。動きを止めた人にも、外側・ボタン・Escape が残っている。

### D6: 焦点は開いた場所へ戻す

いまは戻していない。閉じるとキーボードや読み上げの利用者は画面の先頭から
辿り直すことになる。

開くときに `document.activeElement` を控え、閉じるときに戻す。控えた要素が
消えていた場合（メモを消したあとなど）は何もしない。

## Risks / Trade-offs

- **うっかり外側を押して書きかけが消える** → D2 で受け入れた取引。欄は
  最大3つで、打ち直しは数十秒。
- **引く操作が入力欄のカーソル移動と取り合う** → 入力欄の上から引き始めた
  ときは、その要素にスクロールできる余地があるかを見る（D3 と同じ判定）。
- **Escape はスマホに無い** → 外側と引く操作がその代わりになる。既存の
  コメント（`memo-detail.tsx:166`）が指摘していたのはこの点で、いまは
  両方揃う。
- **シートが2つとも同じ部品になる** → 片方だけ違う閉じ方にしたくなったら
  分岐が要る。いまはその要求が無いので、揃えることを優先する。
